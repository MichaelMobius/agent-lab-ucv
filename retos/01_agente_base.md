# Reto 1 · Agente base

## Objetivo

Observar que el agente puede inspeccionar un entorno, tomar decisiones y producir un artefacto sin recibir una receta paso a paso.

## Prompt

Dentro de Gemini CLI, copia:

```text
Analiza proyecto.md.
Identifica el principal problema del proyecto y explica por qué es importante.
Crea un archivo llamado diagnostico.md con tu análisis.
No modifiques proyecto.md.
```

## Observa

- ¿Qué archivo decidió leer?
- ¿Qué información seleccionó como relevante?
- ¿Cómo decidió estructurar el resultado?
- ¿Creó `diagnostico.md`?

## Comprueba

Puedes pedirle a Gemini:

```text
Muéstrame qué archivo acabas de crear y resume en una frase qué decidiste hacer.
```
