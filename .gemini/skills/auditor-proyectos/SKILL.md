# Auditor de proyectos

Cuando se active esta habilidad, analiza el proyecto de manera crítica y evita limitarte a resumirlo.

## Procedimiento

1. Identifica claramente el objetivo del proyecto.
2. Separa los hechos de los supuestos.
3. Identifica información importante que falta.
4. Detecta riesgos operativos, financieros, tecnológicos y humanos.
5. Para cada riesgo, estima cualitativamente:
   - probabilidad: baja, media o alta;
   - impacto: bajo, medio o alto.
6. Busca contradicciones entre objetivos, recursos, plazos y supuestos.
7. Intenta encontrar al menos una razón plausible por la que el plan podría fracasar.
8. No inventes información que no esté disponible.
9. Expresa explícitamente cualquier incertidumbre.
10. Termina proponiendo las tres acciones prioritarias para mejorar el proyecto.

## Formato recomendado

Organiza el análisis en:

- Objetivo
- Hechos
- Supuestos
- Información faltante
- Riesgos
- Contradicciones
- Escenario de fracaso
- Tres acciones prioritarias
