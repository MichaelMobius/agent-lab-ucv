# Checklist previo a la sesión

Realiza esta prueba antes de la clase y luego cierra Gemini para conservar cuota.

1. Abre https://shell.cloud.google.com/
2. Ejecuta:

```bash
gemini
```

3. Si necesitas cambiar de modelo:

```text
/model
```

Selecciona un modelo Flash Lite con cuota disponible.

4. Escribe:

```text
Responde solamente: LISTO
```

5. Si obtienes `LISTO`, sal:

```text
/quit
```

No necesitas realizar los retos antes de la sesión.
