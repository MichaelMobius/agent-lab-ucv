# Caso opcional · Diseño educativo

Una docente debe diseñar una actividad de 90 minutos para 35 estudiantes adultos con niveles digitales heterogéneos.

## Restricciones

- No todos tienen laptop.
- La actividad debe producir una evidencia observable de aprendizaje.
- La explicación expositiva no puede ocupar toda la sesión.
- Debe existir una alternativa para quien tenga problemas técnicos.

## Reto

Crea un Skill que evalúe diseños de actividades y compruebe:

- objetivo de aprendizaje;
- coherencia entre actividad y objetivo;
- accesibilidad;
- evidencia de aprendizaje;
- plan de contingencia.
